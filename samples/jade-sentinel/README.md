# Jade Sentinel — active user sample

Open a disposable copy of [Sentinelle.ankh](Sentinelle.ankh), keeping `Sentinelle.assets` beside it. The project is byte-identical to the accepted Alpha Jade; five PNG assets remain content-addressed and unchanged. [MIT asset grant](ASSET-LICENSE.txt), [source manifest](sample-source.json).

Eight bones, seven slots, two weighted meshes, `idle` (2s loop) and `attack` (1.5s strike/return, impact0.75s). Default skin, Normal blending, static dark tint, FFD; no constraints or PathPosition. No unsaved Qwen test rig is invented. The source art is five procedural PNGs, not a PSD. Only those project dependencies are required to open it.
