# Jade Sentinel — current user workflow

Jade is the only active character demo. [Project, assets and license](../samples/jade-sentinel/README.md). Source art is five procedural PNGs, no associated PSD identified. The accepted sample has eight bones, seven slots, two weighted meshes/two influences and FFD, static body dark tint, default skin, Normal blending and no constraints. `idle` lasts2s; `attack`1.5s with impact0.75s. Original project/asset bytes are unchanged. Unsaved maintainer Qwen edits are not included.

1. Copy the complete sample into a writable test directory. Run the current local Windows executable. File → Open `Sentinelle.ankh`, keep its adjacent `.assets`, then Save As to a practice path. No compiler/model is needed. File dialogs may need a physical click; no GUI result is claimed here.
2. In Setup inspect Hierarchy and attachment/weight controls. Make a small deliberate change, Undo, Redo, then Undo before continuing. Do not replace weighted meshes with regions. Bones and selection locks are distinct from animation evaluation.
3. Switch Animate and select `idle`/`attack` from the Timeline. Play/pause and scrub0/0.25/0.5/0.75s. Keep the existing poses; on a practice copy add a small key and test Undo/Redo. Read [FFD editing](ffd-key-editing.md), [FFD clipboard](ffd-key-clipboard.md), [clip manager](animation-manager.md) and [selected offset](selected-bone-key-offset.md) before broader edits.
4. Save, close and reopen the practice copy; inspect artwork, clips and assets. Test New/Open/Close **Save / Discard / Cancel** separately. Autosave is isolated from the primary. Recovery Ignore/Recover must be tested only on deliberately interrupted disposable copies; never delete the original recovery sidecar to get a clean screen.
5. Export into a new empty folder. Read preflight: errors block, fidelity losses/replacements require explicit consent, orphans remain. Native v2 produces JSON/atlas for the supported consumer subset. Rendered sequences/sheets use the default skin/Normal blend and refuse physics; JPEG has no alpha. [Export guide](animator/import-export.md), [safety](export-safety.md), [runtime contract](formats/export-runtime.md).
6. Use the external matching runtime public APIs for a supported native export. T836 prepares/qualifies data without adding a browser demo or modifying adapters. No PathPosition/physics/advanced constraint fidelity is implied. [Compatibility](release-compatibility.md).

For PSD import use your own shareable PSD copy or the existing synthetic `formats/tests/fixtures/tagged_rig.psd`, clearly a technical fixture rather than a Jade source. File import preview has Scale/Skip hidden/Replace/Merge; read its report and test Undo/Redo. Never invent a Jade PSD or substitute a different character as the active user demo. Preserve missing-path/reimport safeguards.

The small sample does not cover every historical constraint, invalid topology, many-key performance or crash case. Those keep their technical fixtures in the444-case manual map. No artistic/physical Windows/model test is marked PASS by this guide.
